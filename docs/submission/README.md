# FQCNN Q1 submission package

This directory is the venue-neutral preparation layer for the IEEE Transactions on
Quantum Engineering (TQE) primary target. The reproducible archive is generated
from a clean Git commit by `scripts/build_q1_submission_package.py`; the generated
ZIP is deliberately not committed.

Included preparation documents:

- `cover-letter.md` — editor letter draft for a regular TQE article;
- `author-declarations.md` — all-author, ethics, funding, and conflict checklist;
- `data-code-availability.md` — precise data and software availability statement;
- `reproducibility.md` — commands, locks, evidence scope, and external-data notes.

Before upload, authors must fill the declaration checklist, deposit the code/evidence
archive in a persistent public repository, run the final TQE author-template and
graphics checks, and decide whether the APC is funded. No journal submission or
real-QPU execution is performed by this repository.
